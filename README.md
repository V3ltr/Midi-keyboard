This is a Midi keyboard. 
It uses touch sensors that sense your electromagnetical field and activate sending a signal to the waveshare ESP32 S3 Zero.
It works like a electric keyboard, with switches, buttons, knobs, and sliders that control the sound.
The sound is output from your phone thanks to the waveshare esp.
